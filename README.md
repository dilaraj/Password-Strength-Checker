# Password Strength Checker
A simple, yet powerful password check built with nothing but plain Java

## Features and Functionality
**Input:** Users Password\
**Checks:** 
- Length
- Uppercase Letters
- Lowercase Letters
- Numbers
- Special Characters

**Returns:** 
Password strength calculated using an efficient scoring system:
- 0-2 points -> Weak
- 3-4 points -> Medium
- 5-6 points -> Strong
